# Terminal Configuration for Windows Terminal Customization

If you want BinaryFetch to have the similar appearance shown in the preview below, you can apply the provided `Windows_Terminal_Config.json` configuration to Windows Terminal.

![BinaryFetch Windows Terminal Preview](https://github.com/BinaryFetch-CLI/BinaryFetch/blob/main/Previews/07_preview.png?raw=true)

## How to Apply the Configuration

1. Open **Windows Terminal**.
2. Open **Settings** from the Terminal menu.
3. Select **Open JSON file** to open the Windows Terminal configuration file.
4. Replace the existing configuration with the contents of `Windows_Terminal_Config.json`.
5. Save the file.
6. Restart Windows Terminal.

After restarting, your terminal should use the same configuration and appearance shown in the preview.

> **Note:** Replacing the entire configuration will overwrite your existing Windows Terminal settings. If you have custom profiles or preferences, create a backup of your current JSON configuration before replacing it.
